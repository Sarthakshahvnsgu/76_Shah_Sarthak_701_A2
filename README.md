# Fullstack React Assignment #2

This repository contains the solutions for Assignment #2, divided into three separate project directories (`Q1`, `Q2`, and `Q3`).

## Project Structure

```text
76_Shah_Sarthak_701_A2/
├── Q1/       # React components using CDN approach (Vite + External CDN)
├── Q2/       # React router app for 9 subquestions (Hooks, Forms, JSON Fetch, Search)
└── Q3/       # Task Planner App (CRUD, Filter, Search, LocalStorage)
```

---

## Instructions to Run

### Question 1: CDN React Components (`Q1`)
```bash
cd Q1
npm install
npm run dev
```

### Question 2: React Components & Hooks Router (`Q2`)
```bash
cd Q2
npm install
npm run dev
```

### Question 3: Task Planner App (`Q3`)
```bash
cd Q3
npm install
npm run dev
```

---

## Build for Production

To build any question for production deployment:
```bash
cd Q1  # or Q2 or Q3
npm run build
```
